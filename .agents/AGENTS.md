# Workspace Rules for FINIX Dashboard

## Layout and Preview Consistency
* **Phone Preview Match**: The preview layout (visible via running the `.bat` file, e.g., in Chrome/Edge web mode with mobile emulation) must look **exactly the same** on a real physical mobile phone.
* **Responsive Design & Overflow Prevention**: When building or modifying frontend code, always ensure that layouts, dimensions, font sizes, paddings, and components are responsive and adapt properly to real phone screens. Avoid hardcoded pixel dimensions that could cause overflow or layout issues on different devices.
* **Asset and Styling Consistency**: Ensure that styling, fonts, and assets display consistently across both the browser/preview mode and native mobile platforms.
